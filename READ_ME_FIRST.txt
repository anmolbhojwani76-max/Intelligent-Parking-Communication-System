INTELLIGENT PARKING COMMUNICATION SYSTEM — AUTOMATIC VERSION

1. Extract this ZIP completely into a NEW folder.
2. Install Python 3.10 or later if needed. Python 3.12 is recommended for this package.
3. Double-click INSTALL_WINDOWS.bat once. Internet is needed to download two dependencies.
4. After installation succeeds, double-click START_WINDOWS.bat.
5. The dashboard and sensor station open in your browser.

Dashboard:      http://127.0.0.1:8090
Sensor station: http://127.0.0.1:8091

Vehicles arrive and leave automatically in SIMULATION mode.
For physical automatic detection, choose CAMERA DETECTION on the sensor station.
Enable the webcam, define parking zones, capture the empty reference, then start detection.

No slot-by-slot clicking is required in either mode.
Camera mode detects occupied regions; it does not classify objects as cars.

Keep the terminal open. Ctrl+C stops the complete project.
